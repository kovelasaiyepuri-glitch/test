Frontend (.env)

  • Public Keys Only: Holds SUPABASE_URL and SUPABASE_ANON_KEY.
  • Safe for Browser: The Anon key is protected by Supabase Row Level Security (RLS) policies.
  • Direct Database Reads: Can subscribe to realtime chat updates via Supabase JS client.
  • Zero Private Leaks: Never contains Gemini API keys or Database Admin keys.

Backend (.env)

  • Privileged Secrets: Holds GEMINI_API_KEY and SUPABASE_SERVICE_ROLE_KEY.
  • Elevated Database Admin: Can bypass RLS to perform system migrations, cleanup, and audit logs.
  • AI Orchestrator: Manages conversation history, invokes @google/genai, and streams tokens.
  • Safety Shield: Prevents unauthorized users from depleting quotas or accessing private data.

Database Schema: To initialize the Supabase tables, open the Supabase SQL Editor and run the included supabase_schema.sql file located at the project root.
